# lockin-legal

Les pages publiques de l'application iOS Lockin : politique de confidentialité
et assistance. App Store Connect exige deux adresses joignables sans
authentification, ce dépôt existe pour les servir.

Publiées par GitHub Pages sur https://yoyz-build.github.io/lockin-legal/

Les sources font foi dans le dépôt privé `lockin`, dossier `web/`. Toute
modification s'y fait d'abord, puis se recopie ici.
